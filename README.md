# BOSKU ONE SYSTEM

Working product name: **Bosku One System**. Final product name is intentionally not locked yet.

Bosku One System is a customer, retention, daily-certainty, and business-intelligence layer for **Bosku Cukur**. It complements the existing POS (**Kasir Pro**) rather than replacing it.

## Core principle
> Jangan bangun sesuatu cuma karena bisa dibangun; bangun karena Bosku benar-benar butuh.

## Current product thesis
The primary problem is not lack of a booking app. Bosku is predominantly walk-in. The system should turn uncertainty into usable operational visibility:

**Customer → Visit → Payment → Return Pattern → Due → Reminder → Booking/Walk-in → Repeat → Revenue**

Daily certainty must distinguish:
- Confirmed
- Expected
- Walk-in
- Arrived
- Completed
- Cancelled / No-show

Projected revenue and actual revenue are always separate.

## MVP direction
1. Customer profile + visit history
2. Daily customer certainty
3. Retention / return engine
4. Owner business dashboard
5. Kasir Pro integration boundary
6. Audit, permissions, and failure-tolerant operation

## Explicit non-goals
No new POS, ERP, full accounting, complex queue system, payroll, marketplace, AI hairstyle generator, or dedicated booking app unless later evidence proves a real need.
