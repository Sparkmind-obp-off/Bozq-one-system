# Bosku Daily Operating Workflow

## Opening
1. Arrive around 08:00–08:30/09:00.
2. Clean tools and shop.
3. Sweep and mop.
4. Check clipper/trimmer/machines and charging/readiness.
5. Check consumables and work materials.
6. Eat/breakfast.
7. Stand by for customers.

## Service
1. Customer arrives.
2. Identify customer or create minimal customer record.
3. Check booking/queue context if applicable.
4. Confirm service/price.
5. Perform service.
6. Clean workstation.
7. Record service completion.
8. Handle payment through Kasir Pro as transaction authority.
9. Handle documentation/photo when required.
10. Return to ready state.

## Busy Condition
When multiple customers arrive:
- preserve arrival/order information;
- make current service state visible;
- avoid relying on memory alone;
- record waiting/booking context;
- observe customer drop-off before introducing a larger queue product.

## Closing
1. Review today's operational data.
2. Review daily totals/report.
3. Correct obvious missing data.
4. Prepare report for owner.
5. Send/report using the agreed human-controlled channel.
6. Closing/cleaning.

## Failure Rule
Service completion, payment state, and receipt printing are separate facts.
Printer failure must not cause loss of service history.
