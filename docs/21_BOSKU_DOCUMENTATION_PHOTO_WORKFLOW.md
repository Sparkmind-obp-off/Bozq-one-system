# Bosku Documentation / Photo Workflow

## Problem
After a haircut, documentation/photo can be forgotten because it is outside the core cutting workflow.

## Goal
Make required documentation visible at the correct point without forcing unnecessary work.

## Workflow
SERVICE COMPLETED → DOCUMENTATION STATUS → PHOTO/NOT REQUIRED → SAVED/LINKED → DONE

## Rules
- Documentation requirement must be explicit.
- Do not assume every customer needs a public social post.
- Do not auto-publish to social media.
- Do not block service completion solely because a photo was not taken unless a future business rule explicitly requires it.
- Keep the workflow fast on mobile.

## Future Automation Candidate
If repeated evidence shows that reminders or deterministic routing materially reduce missed documentation, automation may be evaluated.
