# Bosku Opening Readiness & Stock

## Goal
Move opening readiness and basic stock memory from the operator's head into a lightweight checklist.

## Opening Checklist
- Shop clean
- Tools clean
- Clipper ready
- Trimmer/machine ready
- Charging/readiness checked
- Scissors ready
- Comb ready
- Tissue ready
- Hair tonic available
- Shampoo available
- Cape/sarung available
- Other required consumables available

## Exception
If an item is missing or low:
- mark it;
- optionally add note;
- keep service workflow available unless the missing item blocks safe service.

## Current Known Issue
Hair tonic has previously been discovered empty only when needed.

## Boundary
This is not a full inventory/stock-management system. It is an operational readiness memory layer.
