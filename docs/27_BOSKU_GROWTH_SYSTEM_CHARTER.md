# BOSKU GROWTH SYSTEM — PROJECT CHARTER

Status: DRAFT v1.0
Project name: BOSKU GROWTH SYSTEM
Parent system: Bozq One System

## Objective
Membuat Bosku Cukur lebih ramai secara sehat dan membuat pelanggan lama lebih sering kembali.

## Growth loop
Acquire → Visit → Satisfy → Return → Refer → Repeat.

## Scope
- local visibility
- customer acquisition
- service experience
- retention
- loyalty
- WhatsApp follow-up dengan consent
- referral
- content
- review/reputation
- daily/weekly growth reporting

## Ownership
Owner: keputusan komersial dan kebijakan.
Growth Operator / Capster: observasi, eksekusi SOP, pencatatan, follow-up berizin, content capture.
Other Capster: service dan data capture.
System Builder: dokumentasi, automation, software setelah proses terbukti.

## Success
Pelanggan baru naik, repeat customer naik, transaksi naik, average transaction terukur, referral terukur, dan sumber pelanggan diketahui.
