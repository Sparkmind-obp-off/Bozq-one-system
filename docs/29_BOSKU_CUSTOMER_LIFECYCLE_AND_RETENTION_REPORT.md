# BOSKU CUSTOMER LIFECYCLE & RETENTION REPORT

Lifecycle: NEW → FIRST VISIT → SATISFIED → DUE → RETURNING → LOYAL → REFERRER.

Customer record: customer_id, name, WhatsApp, last_visit, visit_count, last_service, capster, source, loyalty_status, consent_status, next_follow_up, notes.

Rules: follow-up hanya untuk kontak yang memiliki dasar/consent sesuai; singkat; personal; tidak spam; hormati opt-out; catat hasil.

KPIs: returning customers, repeat rate, reactivated customers, time between visits, loyalty completion, referral customers.
