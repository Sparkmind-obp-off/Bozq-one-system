# BOSKU DAILY & WEEKLY GROWTH REPORT SPEC

Daily report — prepared by on-duty capster / Growth Operator; reviewed by Owner as needed.

Daily fields: date, transactions, revenue, new customers, returning customers, service mix, average transaction, source, referrals, reactivation visits, complaints, wins, operational issues.

Weekly report — prepared by Growth Operator; reviewed by Owner.

Sections: executive summary; traffic; acquisition; retention; revenue; service mix; referral; content/reputation; bottlenecks; experiments; next actions.

Decision: KEEP / STOP / IMPROVE / TEST NEXT.

Commercial changes require owner approval.
