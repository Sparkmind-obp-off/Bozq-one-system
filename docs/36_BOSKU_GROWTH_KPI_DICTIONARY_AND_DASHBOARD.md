# BOSKU GROWTH KPI DICTIONARY & DASHBOARD

KPIs: Daily Transactions; Daily Revenue; New Customers; Returning Customers; Average Transaction; Repeat Rate; Referral Customers; Reactivation; Source Mix; Loyalty Progress.

Dashboard layers: Today; 7-day trend; 30-day trend; Customer lifecycle; Acquisition source; Service mix; Capster/service operations; Experiments.

Principle: if a metric does not support a decision, it does not belong on the primary dashboard.
